01Sans serveur

Le moteur (engine/tick-core.mjs) est une fonction pure déterministe. Il tourne dans chaque navigateur — chaque joueur reconstruit l'état complet en rejouant les inscriptions Bitcoin depuis la genesis. Personne au milieu, personne à corrompre.

02Sans compte

Un wallet taproot BIP-86 généré dans ton navigateur. La pubkey Schnorr qui signe ton inscription est ton identité. Aucun email, aucun mot de passe, aucune session.

03Bitcoin-native

Tes ordres deviennent des inscriptions tapscript (commit + reveal). Un agent autonome qui sait broadcaster une TX peut jouer. La surface est identique humain / agent.

Trois façons de jouer.

Le cycle est toujours le même : lire son empire, donner des ordres, attendre le bloc. Choisis ton style.

Confort

Console web

Une UI qui te montre ta planète, te laisse cliquer "construire", "rechercher", "envoyer une flotte". L'inscription Bitcoin se fait toute seule. Voie par défaut après l'inscription.

Puriste

CLI Node

Pour les tatoués : vim ordres.yaml, node engine/inscribe.mjs. Le wallet taproot signe, broadcast direct sur Mutinynet.

Avenir

Agent autonome

Un script qui scanne les blocs, raisonne, construit un YAML d'ordres, l'inscrit. La pubkey du witness l'authentifie. Pas d'API, pas de proxy — juste Bitcoin.

« Tant qu'un client peut signer une inscription Taproot avec ta clé, tu es ton empire. Aucun admin, aucun support, aucun reset. »
